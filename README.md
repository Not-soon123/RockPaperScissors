# Rock Paper Scissors

A simple console-based Rock Paper Scissors game built with JavaScript as part of **The Odin Project Foundations course**.

## About the Project

This project is a beginner-level JavaScript exercise where the player plays Rock Paper Scissors against the computer.

The player enters their choice using the `prompt()` function, while the computer randomly selects its choice. The game then determines the winner and keeps track of the scores.

## Features

* Player chooses Rock, Paper, or Scissors using `prompt()`
* Computer randomly selects a choice
* Determines the winner of each round
* Handles ties
* Tracks the player's score
* Tracks the computer's score
* Displays results in the console

## How to Run

Clone the repository:

```bash
git clone https://github.com/Not-soon123/RockPaperScissors.git
```

Move into the project directory:

```bash
cd RockPaperScissors
```

Then run the JavaScript file in a JavaScript environment that supports `prompt()`, such as a browser console.

Follow the prompts and enter:

```text
rock
paper
scissors
```

## Example

```text
Choose rock, paper, or scissors:
> rock

Computer chose: scissors
You win! Rock beats scissors.

Player score: 1
Computer score: 0
```
